מי מפעיל את השירות

סולנה מפעילה את Solna SolarFlow Backup לצורך גיבוי ושחזור פרטיים. מדיניות זו מתייחסת לשימוש בנתוני Google במסגרת שירות הגיבוי ולאתר המידע הציבורי הזה.

גישה ל־Google Drive ומטרתה

לאחר אישור בעל החשבון, תוכנת הגיבוי משתמשת ב־Google Drive API ובהרשאת drive.file. הגישה כוללת יצירה, קריאה, עדכון וניהול של קבצים שנוצרו באמצעות האפליקציה או שניתנה לה גישה אליהם, ומטא־נתונים הדרושים לכך, כגון מזהים, שמות, גודל ומועדי שינוי. אין זו הרשאה לקריאת כלל קובצי Google Drive.

הגישה משמשת להעברת מאגרי גיבוי מוצפנים, לאימותם ולשחזורם. נתוני Google המתקבלים במסגרת שירות הגיבוי אינם משמשים לפרסום, למכירה או לאימון מודלי בינה מלאכותית.

מה נשמר והיכן

קובצי הגיבוי מוצפנים במחשב לפני ההעלאה ל־Google Drive. בעת הכנה או שחזור, מידע לא מוצפן עשוי להימצא במחשב המורשה. אסימוני ההרשאה נשמרים בתצורה המקומית של כלי החיבור; הם אינם נדרשים לאתר המידע ואינם נשלחים אליו.

מפתח הפענוח נשמר בשליטת בעל הגיבוי ואינו מיועד להישמר לצד המאגר בענן או באתר הציבורי. הצפנת התוכן אינה מסתירה מ־Google את חשבון המשתמש או את כל מטא־הנתונים של האחסון. אין במדיניות זו הבטחת אבטחה מוחלטת.

ספקים וגישה למידע

Google מספקת את שירות האחסון וההרשאה בחשבון שנבחר. מפעילי סולנה המורשים עשויים לטפל במידע המקומי לצורכי גיבוי ושחזור. אתר המידע מתארח ב־GitHub Pages; תוכן הגיבויים אינו מועבר ל־GitHub באמצעות האתר. שירותי הספקים כפופים גם לתנאים ולמדיניות שלהם.

שמירה, מחיקה וביטול הרשאה

עותקי גיבוי נשמרים עד שבעל החשבון או מפעיל מורשה מוחקים אותם בהתאם לנוהל השמירה שנבחר. אין הבטחה למחיקה אוטומטית לאחר מספר ימים קבוע. מחיקה בלתי מבוקרת של חלק ממאגר מוצפן עלולה לפגוע בשחזור.

ניתן לבטל את הרשאת האפליקציה דרך החיבורים בחשבון Google. הביטול מונע גישה עתידית באמצעות ההרשאה שבוטלה; הוא אינו מוחק אוטומטית גיבויים קיימים או עותקים מקומיים. לבקשות עיון, תיקון או מחיקה של מידע שבטיפול סולנה ניתן לפנות באמצעות כתובת הקשר למטה.

ביקור באתר המידע

האתר אינו מפעיל טופסי איסוף, התחברות, כלי פרסום או סקריפטים של ניתוח שימוש, ואינו ניגש ל־Google Drive. GitHub מתעדת ושומרת את כתובת ה־IP של מבקרי GitHub Pages לצורכי אבטחה, גם ללא התחברות לחשבון. ספק האירוח עשוי לעבד גם פרטי דפדפן ונתוני בקשה לצורך מסירת האתר ואבטחתו. לכן אין כאן הבטחה שלפיה עצם הביקור אינו יוצר מידע טכני אצל ספק האירוח. מידע נוסף: מדיניות הפרטיות של GitHub ו־מדיניות הפרטיות של Google.

English summary

Solna operates this private backup utility. With the account holder’s consent, it uses the Google Drive API and the per-file drive.file scope to manage files created by or explicitly made accessible to the app, including the metadata needed for backup and recovery. It does not obtain blanket access to the entire Drive.

Backup contents are encrypted locally before upload to the account holder’s Drive. Plaintext may exist on the authorized computer during preparation or recovery. OAuth tokens remain in the local connector configuration. Recovery keys are under the backup owner’s control and are not intended to be stored alongside the cloud repository. Encryption does not hide all storage metadata from Google.

Google data is used for backup and recovery, not advertising, sale or AI model training. Existing backups remain until an authorized operator removes them under the chosen retention procedure. Revoking access through Google does not automatically delete stored backups or local copies. This website has no login, upload form, analytics scripts or Drive API connection. GitHub Pages logs and stores visitors’ IP addresses for security, even when they are not signed in. Its hosting provider may process other technical request information for delivery and security. Privacy requests and questions: SolnaSolar@gmail.com.
